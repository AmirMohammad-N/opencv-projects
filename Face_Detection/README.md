# Project - Face and Eye Detection

## Description

This project demonstrates face and eye detection using Haar Cascade classifiers in OpenCV.

The program detects faces in an image and draws rectangles around them. It also detects eyes within each detected face and highlights them separately.

## Requirements

- Python
- OpenCV
- Matplotlib

## How to Run

```bash
python Face_Detecton.py
```

## Features

- Haar Cascade Classifiers
- Face Detection
- Eye Detection
- Grayscale Conversion
- Histogram Equalization
- Bounding Box Visualization
- Matplotlib Visualization
