# Project 14 - Hough Line Detection

## Description

This project demonstrates line detection using OpenCV.

The program applies Gaussian Blur and Canny Edge Detection to an image, then uses the Probabilistic Hough Line Transform to detect lines and visualize them on the original image.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run

```bash
python opencv_project.py
```

## Features

* Gaussian Blur
* Grayscale Conversion
* Canny Edge Detection
* Hough Line Transform
* Line Detection and Visualization
* Matplotlib Visualization
