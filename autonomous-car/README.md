# Autonomous Car

An autonomous car project using Raspberry Pi, OpenCV, and DC motors.

The car uses a camera to detect lane lines, calculate the lane center, and control the motors to follow the lane.

## Hardware

* Raspberry Pi 4
* Raspberry Pi Camera V3
* L298N Motor Driver
* 2 × DC Motors

## Software

* Python
* OpenCV
* NumPy
* Picamera2
* RPi.GPIO

## Features

* Lane Detection
* Lane Center Detection
* Motor Control
* Basic Lane Following
