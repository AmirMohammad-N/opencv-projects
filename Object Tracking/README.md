# Project - Object Tracking

## Description

This project demonstrates object tracking using OpenCV. The user selects an object in the first frame of a video, and the tracker follows the selected object throughout the video.

The program displays a bounding box around the tracked object, shows the tracking algorithm and FPS, and saves the processed video as an output file.

## Requirements

- Python
- OpenCV

## How to Run

```bash
python "Object Tracking.py"
```

## Features

- Video Capture
- Object Selection
- Object Tracking with CSRT
- Multiple Tracker Options
- Bounding Box Visualization
- Tracking Failure Detection
- FPS Display
- Processed Video Output
