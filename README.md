# Learn OpenCV

This repository contains a collection of Python projects created while learning and practicing OpenCV.

The projects cover image processing, color spaces, drawing, mouse events, camera processing, thresholding, contours, morphological operations, object tracking, edge detection, feature detection, line and circle detection, and image cloning.

## Projects

| Project    | Topic                                |
| ---------- | ------------------------------------ |
| Project 01 | Image Channels and Cropping          |
| Project 02 | RGB and HSV Channels                 |
| Project 03 | Alpha Channel                        |
| Project 04 | Drawing Shapes and Text              |
| Project 05 | Mouse Events and Drawing             |
| Project 06 | Camera and HSV                       |
| Project 07 | Thresholding                         |
| Project 08 | Contours                             |
| Project 09 | Morphological Operations             |
| Project 10 | Blue Object Tracking                 |
| Project 11 | Canny Edge Detection                 |
| Project 12 | ORB Feature Detection and Matching   |
| Project 13 | SIFT Feature Matching and Homography |
| Project 14 | Hough Line Detection                 |
| Project 15 | Hough Circle Detection               |
| Project 16 | Seamless Cloning                     |
