# Project 06 - Camera and HSV

## Description

This project demonstrates how to capture video from a camera and convert each frame from BGR to HSV color space.

The converted video is displayed in a window.

## Requirements

- Python
- OpenCV
- NumPy
- Camera

## How to Run

python opencv_project06.py
