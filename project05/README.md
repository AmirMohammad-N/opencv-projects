# Project 05 - Mouse Events and Drawing

## Description

This project demonstrates how to handle mouse events using OpenCV.

The program allows the user to draw circles on an image by clicking and moving the mouse. It also demonstrates changing the drawing color using keyboard keys.

## Controls

- B - Blue
- G - Green
- R - Red
- ESC - Exit

## Requirements

- Python
- OpenCV
- NumPy

## How to Run

python opencv_project05.py
