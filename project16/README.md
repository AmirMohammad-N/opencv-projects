# Project 16 - Seamless Cloning

## Description

This project demonstrates seamless image cloning using OpenCV.

The program uses the `seamlessClone` function to blend an object or selected region from one image into another image. It also compares `NORMAL_CLONE` and `MIXED_CLONE` methods.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run

```bash
python opencv_project16.py
```

## Features

* Image Resizing
* Mask Creation
* Polygon Masking
* Seamless Image Cloning
* Normal Clone
* Mixed Clone
* Image Blending
* Matplotlib Visualization
