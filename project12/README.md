# Project 12 - ORB Feature Detection and Matching

## Description

This project demonstrates feature detection and feature matching using the ORB algorithm with OpenCV.

The program detects keypoints in an image, computes ORB descriptors, and visualizes the detected features.

It also compares two images using BFMatcher with Hamming distance to find matching features between them. The matches are sorted based on their distance, and the best matching keypoints are displayed.

## Requirements

- Python
- OpenCV
- NumPy
- Matplotlib

## How to Run

python opencv_project12.py

## Features

- ORB Keypoint Detection
- ORB Descriptor Computation
- Feature Visualization
- BFMatcher
- Hamming Distance
- Feature Matching Between Two Images
- Sorting Matches by Distance
- Displaying the Best Matching Features
