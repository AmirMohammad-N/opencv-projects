### Project 17 — `project17/README.md`

## Description

This project demonstrates basic geometric image transformations using OpenCV.

The program applies translation, rotation, transpose, and flipping transformations to an image.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run

```bash
python opencv_project17.py
```

## Features

* Image Translation
* Image Rotation
* Image Transpose
* Image Flipping
* Affine Transformation
* Matplotlib Visualization
