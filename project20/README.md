# Project - Background Subtraction using KNN

## Description

This project demonstrates background subtraction using OpenCV's K-Nearest Neighbors (KNN) algorithm.

The program separates moving foreground objects from the background in a video and displays both the original frames and the foreground mask.

## Requirements

- Python
- OpenCV

## How to Run

```bash
python opencv_project20.py
```

## Features

- Video Capture
- KNN Background Subtraction
- Foreground Mask Generation
- Frame Number Display
- Real-Time Video Display
- Foreground and Background Separation
