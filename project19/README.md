# Project - Optical Flow Tracking

## Description

This project demonstrates object feature tracking using the Lucas-Kanade Optical Flow algorithm in OpenCV.

The program detects feature points in a video, tracks their movement between consecutive frames, draws motion trails, and saves the processed video as an output file.

## Requirements

- Python
- OpenCV
- NumPy

## How to Run

```bash
python opencv_project19.py
```

## Features

- Video CaptureS
- Feature Point Detection
- Lucas-Kanade Optical Flow
- Pyramidal Optical Flow
- Motion Trail Visualization
- Video Output Saving
- Real-Time Frame Display
