# Project 15 - Hough Circle Detection

## Description

This project demonstrates circle detection using the Hough Circle Transform with OpenCV.

The program detects circular objects in an image, draws their centers and detected circles, and counts the number of detected objects.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run

```bash
python opencv_project15.py
```

## Features

* Grayscale Conversion
* Median Blur
* Hough Circle Transform
* Circle Detection
* Circle Center Detection
* Object Counting
* Visualization with Matplotlib
