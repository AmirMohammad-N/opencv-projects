# Project - Harris Corner Detection

## Description

This project demonstrates corner detection using the Harris Corner Detection algorithm in OpenCV.

The program converts an image to grayscale, detects corners using the Harris algorithm, and highlights the detected corners on the original image.

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run

```bash
python opencv_project18.py
```

## Features

* Grayscale Conversion
* Harris Corner Detection
* Image Dilation
* Corner Thresholding
* Corner Visualization
* Matplotlib Visualization
